# 📓 Guía para Google NotebookLM — Capítulo 3

## 🚀 Pasos para crear el Podcast y Estudio del Capítulo 3

1. Abre tu libreta en [notebooklm.google.com](https://notebooklm.google.com/).
2. Añade como fuente el archivo:
   - `docs/tutorials/capitulo_3/material_didactico.md`
   - *(Opcional)* `docs/ARQUITECTURA_GRAFOS.md`
3. Genera el **Audio Overview (Deep Dive)** para escuchar a los locutores debatiendo sobre grafos de conocimiento locales y extracción de relaciones sin nube.
