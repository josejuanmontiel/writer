# 📓 Guía para Google NotebookLM — Capítulo 5

## 🚀 Pasos para crear el Podcast y Estudio del Capítulo 5

1. Abre tu libreta en [notebooklm.google.com](https://notebooklm.google.com/).
2. Añade como fuente el archivo:
   - `docs/tutorials/capitulo_5/material_didactico.md`
3. Genera el **Audio Overview (Deep Dive)** para escuchar a los locutores debatiendo sobre cómo "podar" lecciones sobrecargadas sin miedo a perder material valioso.
