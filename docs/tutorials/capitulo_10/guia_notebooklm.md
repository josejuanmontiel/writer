# 📓 Guía para Google NotebookLM — Capítulo 10

## 🚀 Pasos para crear el Podcast y Estudio del Capítulo 10

1. Abre tu libreta en [notebooklm.google.com](https://notebooklm.google.com/).
2. Añade como fuente el archivo:
   - `docs/tutorials/capitulo_10/material_didactico.md`
   - *(Opcional)* `docs/MANUAL_DE_USUARIO.md`
3. Genera el **Audio Overview (Deep Dive)** para escuchar el episodio final de cierre de la masterclass debatiendo sobre el impacto de la colaboración Git y la producción multiformato.
