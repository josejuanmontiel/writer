# 📓 Guía para Google NotebookLM — Capítulo 4

## 🚀 Pasos para crear el Podcast y Estudio del Capítulo 4

1. Abre tu libreta en [notebooklm.google.com](https://notebooklm.google.com/).
2. Añade como fuente el archivo:
   - `docs/tutorials/capitulo_4/material_didactico.md`
3. Genera el **Audio Overview (Deep Dive)** para escuchar a los locutores analizando la metáfora del semáforo de madurez y el buffer de ideas sin asignar.
