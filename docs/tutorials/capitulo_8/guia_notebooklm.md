# 📓 Guía para Google NotebookLM — Capítulo 8

## 🚀 Pasos para crear el Podcast y Estudio del Capítulo 8

1. Abre tu libreta en [notebooklm.google.com](https://notebooklm.google.com/).
2. Añade como fuente el archivo:
   - `docs/tutorials/capitulo_8/material_didactico.md`
   - *(Opcional)* `docs/ARQUITECTURA_GRAFOS.md`
3. Genera el **Audio Overview (Deep Dive)** para escuchar a los locutores analizando la importancia del linter de conocimiento y la navegación en 2D.
